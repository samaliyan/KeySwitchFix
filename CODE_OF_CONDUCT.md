# Code of Conduct

KeySwitchFix contributors are expected to keep project spaces welcoming, technical, and respectful.

## Expected behavior

- Be considerate and constructive.
- Focus criticism on code and observable behavior, not people.
- Respect differences in language, experience, identity, and background.
- Protect privacy: never request or publish passwords or private typed text.
- Accept maintainer decisions about safety, scope, and false-correction risk.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized content, doxxing, deliberate disruption, and publishing another person's private information are not tolerated.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile. Maintainers may edit or remove content, close discussions, or temporarily or permanently restrict participation when necessary.
